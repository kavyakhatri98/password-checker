[# Password Strength Checker 

## About
This is a beginner-friendly cybersecurity project built using Python. It checks whether a password meets basic validation requirements.

## Features
- Detects common passwords using a predefined list.
- Checks whether the password is at least 8 characters long.
- Checks for uppercase and lowercase letters.
- Checks for numbers and special characters.
- Displays feedback about password requirements.

## Technologies Used
- Python 3
- Python `string` module

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python password_checker.py`

   On Windows, you can also try `py password_checker.py`.

## Learning Outcomes
This project helped me practise Python functions, conditional statements, variables, and string operations while exploring a basic cybersecurity concept.
